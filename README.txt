Tumux for your phone (installable web app)

Put every file in this folder online together, for example with GitHub Pages:
  1. Create a new repository and upload all these files to its main folder.
  2. Repository Settings > Pages > Deploy from a branch > main > /(root).
  3. Open the https link on your phone in Chrome, then menu (three dots) > Add to Home screen / Install app.

Weather, notifications, the offline mode and the PIN lock need the https link.
Your data stays on the phone, in the browser's storage for that link.
